## 01 一条规则

一个项
要么是变量
要么是抽象
要么是应用

计算只发生在一件事上
把参数放进它该在的位置

(λx. M) N → M[x := N]

没有循环
没有赋值
没有类型

一条规则反复用
就能长出加法 乘法 递归
还有整个可计算的世界

## 06 同义与边界

同一个意思
可以有很多种写法

eq 说它们不同形
conv 说它们同义

同义
不等于同形

但同义也有边界

(mul add add a b c)′ = (c′^b′) × (a′+c′)
(add mul add a b c)′ = c′^(a′×(a′+b′))

一个流行的说法是
mul add add 需要四个邱奇数

动手算一遍
三个就够了

写法一变
结论就可能变

“同一含义
是一个很大的限制条件”

所以它把定义 环境 每一步
都摊开

能复现
才能讨论
